# Offload 论文资料

| 目录 | 论文 | 版本说明 |
| --- | --- | --- |
| [2021-zeroinfinity](2021-zeroinfinity/README.md) | ZeRO-Infinity | SC21 论文内容；另附官方演示稿 |
| [2024-speedloader](2024-speedloader/README.md) | SpeedLoader | NeurIPS 2024 官方 Conference PDF |
| [2025-ratel](2025-ratel/README.md) | Ratel（LoHan 接收版本） | ICDE 2025 作者公开接收版本 |
| [2026-megatrain](2026-megatrain/README.md) | MegaTrain | COLM 2026 接收；公开 PDF 为 arXiv 稿 |
| [2026-superoffload](2026-superoffload/README.md) | SuperOffload | ASPLOS 2026 接收/发表；公开 PDF 为 arXiv 稿 |
| [2027-zenflow](2027-zenflow/README.md) | ZenFlow | SIGMOD 2027 接收、to appear；公开 PDF 为 arXiv v3 |

其中，Ratel 是 LoHan 更名后的 ICDE 接收版本；ZenFlow 的 2027 年份按接收会议年份命名，而不是按 2025 年 arXiv 首次提交年份命名。
